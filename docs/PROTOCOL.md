# Protocol — P010 CF9510M 語音檔對照（依網頁模擬層整理）

來源：`index.html` 的 `CF_FILE_MAP`、`buildCfPathMap()`、`CF_NUMBER_MAP`、`getCfNumberSeq()`、`textToCfSequence()`（約第 965～1090 行）。
這是**網頁端的模擬對照**，說明實體版 CF9510M 應該準備哪些 MP3；尚未與實體 SD 卡內容或 Arduino 韌體核對。

## 拆句規則

網頁每次 `speak(text)` 時，`textToCfSequence()` 依序比對：

1. 固定句子（`CF_FILE_MAP`，由長到短優先比對）
2. 阿拉伯數字（0～99，轉成數字檔組合）
3. 路線名稱

比對成功的片段依序列成 `[資料夾, 檔號, 名稱]`，顯示在右側「CF9510M 播放紀錄」面板。例如「你已經踩錯了 3 個紅色的跳石！」→ 1/009、4/003、1/010。

## 資料夾 4：數字

- 檔號 0～10：零、一 … 十。
- 檔號 20、30 … 90：二十、三十 … 九十。
- 11～19 播「十」＋個位數；21～99 播「幾十」＋個位數（個位為 0 時只播幾十）。

## 未涵蓋

- 遊戲中的旋律音符是網頁 Web Audio 合成（`SFX.melodyNote`），實體版要另外準備音符音檔或改用其他發聲方式，目前無對照。
- 資料夾 3、5、6 在網頁中沒有使用。
- 實體 CF9510M 的指令格式見作者的 CF9510M 規格（路徑播放指令），不在此倉庫。
